## Overview

**Still Being Written** is not a traditional birthday website.

It is an interactive cinematic experience that blends storytelling, modern web animation, thoughtful UI design, and emotional narrative into a single-page experience.

Rather than focusing on balloons or conventional birthday decorations, the project explores ideas of growth, character, resilience, curiosity, and hope through immersive interactions.

The goal is simple:

> Create something memorable enough that someone doesn't just visit it—they experience it.

This project intentionally avoids traditional birthday website clichés.

Instead, it focuses on:

* Emotion over decoration.
* Storytelling over presentation.
* Interaction over static content.
* Experience over information.

Every animation should have purpose.

Every transition should feel intentional.

Every interaction should contribute to the narrative.
